# Inter-LAN Communication Using Cisco Packet Tracer

## Project Overview

This project focuses on designing and configuring a network that enables communication between two Local Area Networks (LANs) using a router and a switch.

## Objectives

* Understand basic network topology.
* Configure IPv4 addresses.
* Establish communication between two LANs.
* Understand the role of routers and switches.
* Test connectivity using ICMP Ping.
* Observe packet transmission using Simulation Mode.

## Network Components

* Cisco Router
* Cisco Switch
* End Devices (PCs)
* Ethernet Connections

## Technologies

* Cisco Packet Tracer
* IPv4 Addressing
* Routing
* ICMP
* Network Troubleshooting
